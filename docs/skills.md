# スキル（AIを通さない処理）

文字起こしの後、AIへ渡す前に振り分け層を置く。決まった言い回しに一致した発話は、スキルがプログラム側で入力を検証して実行する。どのスキルにも一致しなければ従来どおりAIへ渡す。AIの権限は広げない。

```text
文字起こし → 制御語（会話終了など） → スキル（登録順に試す） → 一致なし → AI
```

## 仕組み

- `usecase.Skill`（`Name`と`Match`）を満たす型を`cmd/wakeword/app.go`の`newSkills`に登録する。Goの動的プラグイン（`.so`）は使わず、ビルド時に組み込む。
- `Match`は副作用を持たず、一致した場合だけ実行する処理を返す。判定は規則ベース（正規表現）で、AIによる分類はしない。質問の形の発話は一致させない。
- 返答はAIの返答と同じ経路で文ごとに合成・再生する。スキルの依頼と返答も会話履歴（メモリのみ）に残し、続けてAIへ「さっき何を追加した？」と聞けるようにする。
- スキルが失敗したら「依頼を処理できませんでした。」と読み上げ、エラーとして記録して待ち受けに戻る。
- スキルは設定の`[skills.*]`で有効にする。既定はすべて無効。
- スキルは任意で`usecase.SkillVocabulary`（`Vocabulary`）を実装できる。有効なスキルの語彙をまとめ、whisper-serverへ`prompt`（認識のヒント）として渡す。Whisper baseは短い語を誤りやすく、ヒントなしでは「メモ」が「目も」、「ToDo」が「どうぞ」、「買い物」が「カイモノ」になった。ヒントはAIへの質問の文字起こしにも同じく渡る。

## リスト（`[skills.lists]`）

macOSのリマインダー.appのリストへ追加し、未完了の項目を読み上げる。`shopping`・`todo`・`memo`に保存先のリスト名を書く。リストは事前にリマインダー.appで作成する。起動時にリストの有無を確認し、ない場合は起動しない。

| 種類 | 言い回しの例 |
| --- | --- |
| 追加 | 「買い物リストに牛乳を追加して」「牛乳を買い物リストに入れといて」「ToDoに歯医者の予約を登録して」 |
| メモ | 「明日は燃えるゴミの日とメモして」「明日は燃えるゴミの日、メモして」「メモ、駐車場は3階」 |
| 読み上げ | 「買い物リストを読み上げて」「やることリストに何がある？」 |

- 追加後に「買い物リストに『牛乳』を追加しました。」と、保存された項目名を読み返す。誤認識に気づけるようにするため。リスト名はヒントで正しく認識されても、項目は誤認識され得る（合成音声で「歯医者」が「会社」、「明日は燃えるゴミの日」が「あすはモエルゴミの人」になった）。
- 項目は60文字以内、制御文字を含まないものに限る。1回の発話で1項目として登録する（「牛乳と卵」は1項目になる）。
- 読み上げは未完了の項目を最大10件。それ以上は件数だけ伝える。
- 操作は`osascript`でAppleScriptを実行する。リスト名と項目はスクリプトに埋め込まず、`--`の後ろに引数として渡す。osascriptのエラー出力には項目名が含まれ得るため、エラー番号だけを記録する。
- 初回はmacOSが、起動元のアプリ（ターミナルなど）にリマインダーの操作の許可を求める。LaunchAgentから起動する場合の許可の扱いは未確認。
- リマインダーにiCloudを使っている場合、登録した項目はiCloudへ同期される。会話履歴や音声は保存しない。

### 検証記録（2026-10-04）

- 単体テスト：言い回しの判定（質問を一致させないことを含む）、追加後の読み返し、読み上げ件数の上限、偽のosascriptでの引数の渡し方・エラー番号のみの記録・タイムアウト、振り分け層（一致時にAIを呼ばない、不一致時はAIへ渡す、失敗時の読み上げ）。
- 実機（macOS 26.5.2、リマインダー.app）：リスト一覧の取得は約0.7秒、未完了項目7件の取得は約1.9秒。存在しないリストを指定すると起動時エラーになることを確認。
- 実機の一往復：macOSの`say`（Kyoko）で作った3件の依頼WAVを`--request-wav`で順に流した。語彙ヒントの導入前は、文字起こしが「カイモノリスト…」「…目もして」となり、3件ともAIへ渡った（AIは読み取り専用で、書き込みは起きていない）。導入後は3件ともスキルが処理し、買い物に「牛乳」、メモに「あすはモエルゴミの人」が登録されたことをリマインダーで確認した。確認後にテスト項目は削除した。
- 応答時間（録音完了から）：追加は最初の再生まで約3.2〜3.7秒、うちosascriptでの追加が約2〜2.5秒。読み上げ依頼は約1.9秒。AIへ渡した場合は4.1〜6.0秒だった。
- 未確認：人の声での一往復、マイクで待ち受けた状態での利用、ToDoへの実機登録。

# Wakeword Voice Server

常駐する音声サーバーでウェイクワードを検出し、呼びかけ後の音声入力をCodexやChatGPTにつなぐためのプロジェクトです。

## 目指す使い方

1. 音声サーバーを起動し、マイクからの入力を待ち受ける。
2. ウェイクワードで音声入力を開始する。
3. 発話の終了を検出し、音声をテキストに変換する。
4. 設定した連携先のCodexまたはChatGPTへ入力を渡す。
5. 処理後は再びウェイクワードの待ち受けに戻る。

## 想定する構成

```text
マイク → ウェイクワード検出 → 発話区間の検出 → 音声認識 → 連携先への入力
                                                                   ├─ Codex
                                                                   └─ ChatGPT
```

## 初期の開発範囲

- 連携先の切り替え
- 待機中・録音中・処理中の状態表示
- 停止操作とエラー時の待ち受け復帰

## 音声データの扱い方針

待ち受け中の音声はローカルで扱い、外部送信が必要な場合はウェイクワード検出後の発話に限定する方針です。音声や文字起こしを保存するか、保存期間をどうするかは実装前に決めます。認証情報はコードやログに含めません。
